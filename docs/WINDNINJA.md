# Wind field files

HuofengEarth can display locally generated WindNinja or compatible ASCII wind-grid outputs. The software repository does not include example model inputs or outputs.

## Load a field

Use the WindNinja control in the application to open a local results folder or select a velocity grid. For a single field, provide matching velocity and direction grids with the same dimensions, projection, and grid origin. Include the projection file when the grid is not already in geographic coordinates.

The application projects supported grids for display and can group multiple time or height levels when they follow a consistent folder layout. Confirm the input units, projection definition, grid spacing, and timestamps before interpreting the visualization.

## Privacy

Wind fields and associated observations can reveal operational locations. Open files from a location you control, and do not attach real inputs, outputs, or screenshots with sensitive coordinates to public issues. See [DATA-POLICY.md](../DATA-POLICY.md).
